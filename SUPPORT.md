# Support

EZdeploy is currently pre-release software maintained on a best-effort basis.

- Use [GitHub Discussions](https://github.com/jingchang0623-crypto/ezdeploy/discussions) for
  setup questions once Discussions is enabled.
- Use [GitHub Issues](https://github.com/jingchang0623-crypto/ezdeploy/issues) for reproducible
  bugs and feature proposals.
- Follow [SECURITY.md](./SECURITY.md) for vulnerabilities; never disclose them in a public issue.

No production SLA or commercial support commitment is provided by the open-source project.
